# 53: Idea: Despite The Name, Claude Code Is Not (Necessarily) Just About Code

## 1. Lesson Overview

A short idea lesson: the remote features run Claude Code on a computer, and that can be used for more than programming.

## 2. Key Concepts

**A general assistant on your machine**
- *Simple:* Anything Claude Code can do on your computer, you can ask for remotely.
- *Technical:* Dispatch and remote control simply invoke Claude Code on a computer, so the task does not have to be about code.

## 3. Important Terminology

| Term | Meaning | Why it matters |
|---|---|---|
| VPS | Virtual Private Server: a rented computer on the internet | Can run Claude Code around the clock |

## 5. Examples

- With browser access, ask it to do something in your browser.
- Ask it to prepare an Excel file or a presentation.
- Install the CLI on a remote server (VPS), start remote control there, and send it commands from the mobile app.

## 8. Connections Between Concepts

Builds on dispatch (`lesson-50.md`), remote control (`lesson-51.md`), and browser access (Section 2, `lesson-43.md`). The course itself stays with coding use cases.
