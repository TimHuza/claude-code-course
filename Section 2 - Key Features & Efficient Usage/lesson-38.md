# 38: On Custom Commands

## 1. Lesson Overview

A short notice before the next lecture: the "Custom Commands" feature has essentially been merged into "Skills".

## 2. Key Concepts

- Custom commands and skills have overlapping purposes.
- Custom commands **still exist** and still work as shown in `lesson-39.md`.
- You can use skills instead (see `lesson-36.md` for a command-style skill).
- The official Claude Code documentation no longer explicitly mentions custom commands, which is why this note exists.

## 7. Common Beginner Mistakes

- **Thinking the feature was removed.** It was merged, not deleted.
- **Thinking you need both.** Skills alone are enough.
