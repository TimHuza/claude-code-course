# 10: Choosing AI Models

## 1. Lesson Overview

A short note on picking which AI model Claude Code uses. After this you should know how to check and change the model.

## 2. Key Concepts

**The model is selectable**
- *Simple:* Claude Code is the tool; the model is the "brain" inside it, and you can choose which brain.
- *Technical:* Anthropic offers several models with different capability, speed, and cost. The lesson names **Opus** as the most capable.

## 3. Important Terminology

| Term | Meaning | Why it matters |
|---|---|---|
| Model | The AI that reads your prompt and produces the answer | Affects quality, speed, and usage |
| Slash command | A command starting with `/` typed inside Claude Code | How you control the tool itself |

## 6. Important Facts

- `/model` – choose the AI model.
- `Option + P` (macOS) / `Alt + P` (Windows, Linux) – shortcut to switch model.
- You rarely change it, but **check it once at the start**.

## 7. Common Beginner Mistakes

- **Never checking the model.** You may be working with a weaker model than you intended.
- **Confusing Claude Code with the model.** Claude Code is the tool; Opus (etc.) is the model it uses.

## 8. Connections Between Concepts

`/model` is one of many slash commands, like `/config` from `lesson-9.md`. The model also determines the context window size discussed in `lesson-11.md`.

> **Note:** model names and which one is "most capable" change over time, so trust what `/model` shows you over the lesson text.
