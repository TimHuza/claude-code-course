# 8: A Glimpse At The Claude Desktop App

## 1. Lesson Overview

A quick preview of the other ways to use Claude Code besides the terminal: the desktop app and the mobile app. After this you should know these exist and that the course still focuses on the CLI.

## 2. Key Concepts

**Claude desktop app**
- *Simple:* A normal installable app (macOS and Windows) that includes Claude Code.
- *Technical:* The app has several modes:
  - **Chat** – a general chatbot (like ChatGPT), not specifically for coding.
  - **Cowork** – Anthropic's general work assistant; a different product, not covered in this course.
  - **Code** – Claude Code itself.

**Claude mobile app**
- *Simple:* Claude on your phone, also with chat and code modes.
- *Technical:* In code mode you can dispatch and manage cloud tasks, and also dispatch tasks to your local system. Covered later in the course.

## 3. Important Terminology

| Term | Meaning | Why it matters |
|---|---|---|
| Session | One conversation / working run with Claude Code | The unit of work in every interface |
| Working directory | The project folder Claude Code operates in | You must pick one when starting a session |
| Dispatch a task | Hand a task to Claude Code to work on | How the apps are used |

## 4. How Things Work

Starting a coding session in the desktop app:

1. Install the app and log in.
2. Click **New Session**.
3. Select a folder (one you used before, or a new project).
4. Type your prompt and send the task.

## 6. Important Facts

- Desktop app downloads: macOS and Windows.
- The CLI is described as the main Claude Code product, used by most developers.
- You may follow the course with the desktop app instead of the CLI.

## 7. Common Beginner Mistakes

- **Confusing Chat, Cowork, and Code.** Only the Code mode is Claude Code.
- **Thinking the app is a different tool.** It is another interface to the same thing you run with `claude`.

## 8. Connections Between Concepts

You now know three interfaces: CLI (`lesson-4.md`), IDE integration (`lesson-7.md`), and the desktop/mobile apps.
