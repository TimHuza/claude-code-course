# 5: Claude Code in Different Terminals

## 1. Lesson Overview

A short note: Claude Code runs in whatever terminal you choose, but keyboard shortcuts differ between terminals and operating systems. After this you should know to check the official docs when a shortcut does not work for you.

## 2. Key Concepts

**The terminal is your choice, the shortcuts are not universal**
- *Simple:* Any terminal works, but the same key combination may behave differently in each.
- *Technical:* Shortcuts depend on the platform (Windows, macOS, Linux) and the terminal app. Some terminals need extra configuration.

## 5. Examples

Entering a **line break** (a new line in your prompt without sending it) may be:

- `Shift + Enter`
- `Option + Enter` (macOS) / `Alt + Enter` (Windows, Linux)
- or something else, depending on your terminal

The section's cheat sheet also lists `Ctrl + J` for a new line.

## 6. Important Facts

- Pressing `Enter` alone sends the prompt.
- The official documentation lists supported shortcuts and setup steps per terminal.

## 7. Common Beginner Mistakes

- **Assuming the instructor's shortcuts must work for you.** If one does not, it is probably your terminal or platform, not a broken install.

## 9. Practical Understanding

Find out once which line-break shortcut works in your terminal. You will need it for every multi-line prompt.
