# 6: Using Bun

## 1. Lesson Overview

A short setup note about the demo project. It uses **Bun** instead of Node.js, so you need Bun installed only if you want to follow along with the demo (which is optional).

## 2. Key Concepts

**Bun**
- *Simple:* A program that runs JavaScript/TypeScript code on your computer, like Node.js does.
- *Technical:* A JavaScript runtime. The course uses some Bun-only features, specifically Bun's built-in SQLite client (SQLite is a small database stored in a single file).

## 3. Important Terminology

| Term | Meaning | Why it matters |
|---|---|---|
| Runtime | The program that executes your code | The demo project will not run without it |
| Node.js | The most common JavaScript runtime | What Bun replaces here |
| SQLite | A lightweight file-based database | Used later in the demo through Bun |

## 6. Important Facts

- Install link: https://bun.com/docs/installation
- Following along is optional.

## 7. Common Beginner Mistakes

- **Thinking Claude Code needs Bun.** It does not. Bun is only required by the instructor's demo project.
