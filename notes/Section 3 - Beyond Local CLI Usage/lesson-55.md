## 2. Key Concepts

- The course covered the key features needed to use Claude Code efficiently.
- There are two working styles, and you can use either or both:
  - **Autonomous** – running Claude Code in a loop (Section 2, `lesson-45.md`).
  - **Step by step** – plan mode with yourself in the loop (Section 2, `lesson-27.md`).
- Software is increasingly written by AI, but the software engineer steers what is written and how.

> **Transcript note:** "Cloud Code" and "Rolf loop" are Claude Code and the Ralph loop.
